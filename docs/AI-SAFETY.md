# AI safety

Disha is an AI guide, labelled on every reply. She does not promise jobs, rank a trade as best, or give medical, legal, or financial advice beyond scheme facts already stored.

Risks and controls:

| Risk | Control |
| --- | --- |
| Invented earnings | Slot tokens, SQL facts, digit scan, one retry, then ScriptedBrain |
| Prompt injection | Tools are not exposed to the model; no URL fetch; HTML is not rendered as HTML from the model |
| Distress | Helplines and an immediate human offer |
| Minor | Age band, simulated parental consent, no Aadhaar |
| Bias | Counterfactual eval pairs; no trade is chosen from gender or surname |

Report a wrong number from the evidence drawer path into the report flag queue when a family uses the quality API. Sensitive chats show CHILDLINE 1098 and Tele-MANAS 14416.
