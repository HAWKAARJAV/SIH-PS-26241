# Data dictionary

OutcomeStat.scope is provider, district, or state. placement_rate is 0–1. Earnings are rupees per month. tier is V0–V3. status live is visible to families; pending_verification is not.

Trade.nsqfLevel is a decimal with nsqfFrameworkVersion. Do not assume levels 1–10.

District.lgdCode stays null unless a real code is supplied.

Dataset.kind synthetic or evaluation. The organiser label is “Evaluation dataset (provided by organisers — dummy)”.
