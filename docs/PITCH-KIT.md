# Pitch kit

## Six slides

1. The parent often decides. Counsel the household, not only the learner.
2. Family Room: two voices, one session, a join code when migration splits the phone.
3. Trust: every figure has tier, period, n, and source. The model cannot type the number.
4. Honest trade-offs, including “not for you if”, and a degree path beside the trade.
5. Admins see where resistance sits. Counsellors get a consented brief.
6. Demo data is labelled. Organiser files enter through maker-checker.

## Impact and cost (assumptions flagged)

Assumption: one state help-desk pilot, 50 centres, one counsellor per 10 centres. Assumption: software hosting is a single Node service plus SQLite or a small Postgres. Do not quote a rupee impact. No user-test result is claimed.

## Hard questions

1. Where do numbers come from? OutcomeStat rows with a source. V0 is demo.
2. Can the model hallucinate a salary? The digit guard must return zero unsupported numbers in eval.
3. Minors? Age band, purpose consent, simulated OTP labelled as simulated, no Aadhaar.
4. Why not only WhatsApp? WhatsApp can carry the plan image. The room needs a shared ledger and evidence cards.
5. 28 states? District table and cartogram. Language packs are files. No fake LGD codes.
6. SIDH? Deep link out. Enrolment stays on SIDH. Adapters here are mocks.
7. Bias? Counterfactual pairs in eval. No “best trade for girls”.
8. Offline? Service worker caches the shell and offline page. Chat needs a network.
9. DPDP? Minimum data, delete, withdraw, k-anonymity. Re-verify rule dates.
10. Who edits facts? Maker-checker. Pending PLFS rows stay hidden.
11. How is resistance measured? The formula in METHODOLOGY. It is not a causal claim.
12. What is different? The family layer, the number guard, and the resistance map together.
13. Voice? Browser speech, with type as fallback. Bhashini is a mock until keys exist.
14. Fraud centres? Checklist and a weak-provider example. No guarantee language.
15. Women’s safety? Hostel, transport, girls-only fields, and a travel objection tag.
16. Degree pressure? Ladder plus an explicit degree column with no invented wages.
17. Scalability? Stateless app, SQLite for the hall, Postgres for a pilot.
18. Content governance? Playbooks have review status. Machine translations are marked.
19. Cost of counsellors? Not estimated as a fake saving. SLA in the prototype is 4 hours.
20. What fails on stage? Demo mode needs no network model. Reset is on the demo hub.
