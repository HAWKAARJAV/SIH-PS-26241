# Product requirements

Nourish helps a learner and a parent choose a vocational path with source-cited local outcomes, a human handoff, and an admin view of resistance.

Users: learner 15–25, parent, counsellor, scheme admin, data steward.

Must: joint chat in English, Hindi, Marathi, and Tamil; evidence cards; escalation; admin resistance; importer; demo mode without keys.

Must not: invent numbers, claim official status, collect Aadhaar, or rank a trade as best.
