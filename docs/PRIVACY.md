# Privacy

Aligned with the DPDP Act 2023 and the phased rules described in the fact pack (re-verify dates before a demo).

| Data | Why | Who sees it |
| --- | --- | --- |
| Language, district, age band | Counselling | Family room and, if consented, counsellor brief |
| Transcript | The conversation | Family; counsellor only with sharing consent; never admin |
| Analytics events | Resistance maps | Staff, grouped, hidden under k=10 |
| Staff password hash | Sign-in | Not shown |

No Aadhaar, no PAN, no third-party tracker. Delete and withdraw live on the privacy page. Default transcript retention is 90 days (job not yet a cron; the constant is `RETENTION_DAYS`).
